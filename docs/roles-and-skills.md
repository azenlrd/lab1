## Roles and responsibilities

1.  **Mobile Developer (iOS/Android)**
    - Develops and maintains the user-facing application.
    - Implements UI components and integrates with backend APIs.
    - Optimizes app performance and battery usage.

2.  **Backend Developer (Go/C++)**
    - Designs and implements high-load microservices.
    - Writes efficient, concurrent code for processing millions of requests.
    - Ensures service scalability and reliability.

3.  **Site Reliability Engineer (SRE)**
    - Manages infrastructure, monitoring, and incident response.
    - Automates deployment processes and ensures system uptime.
    - Conducts post-mortems and optimizes system reliability.

4.  **Data Scientist**
    - Builds predictive models for pricing, ETA, and demand forecasting.
    - Analyzes large datasets to improve matching algorithms.
    - Conducts A/B tests to validate algorithm changes.

5.  **Security Engineer**
    - Conducts security audits and penetration testing.
    - Implements authentication and authorization mechanisms (OAuth, JWT).
    - Monitors for suspicious activity and vulnerabilities.

## Common skills across roles

- **Git & Version Control:** Proficiency in branching, merging, and resolving conflicts is essential for collaboration.
- **Problem Solving & Algorithms:** Strong understanding of data structures and algorithms is required for efficient coding and optimization.
- **Communication:** Ability to explain technical concepts to non-technical stakeholders (Product Managers, Designers).
- **English Language:** Reading technical documentation and communicating in international teams.
- **Agile Methodologies:** Understanding of Scrum/Kanban workflows.
